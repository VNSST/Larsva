# Kill Chess — Android app

The Android app for Kill Chess. Larsva.com no longer hosts the playable game.
`/games/killchess` is the download page (`app/games/killchess/page.tsx`), and it serves
the APK from `public/downloads/killchess.apk`.

- `www/`: the game (HTML/JS). Edit the game here. It started as the web copy exported
  from the killchess repo; links are now local (`leaderboard.html`, `stats.html`).
- `android/`: the native project, generated by Capacitor.
- `assets/`: source images for the app icon and splash screen.

The app still uses the larsva.com API (`https://larsva.com/games/killchess/api/*`) for
accounts, the leaderboard, stats and online games. Requests go through Capacitor's native
HTTP (`CapacitorHttp` in `capacitor.config.json`), so the API needs no CORS settings.

**Invite links:** online-game invites are `https://larsva.com/games/killchess?play=<id>`.
That page's "Open in app" button fires `killchess://play?id=<id>`, which the app handles in
`www/auth.js`.

**Password reset:** reset emails link to `https://larsva.com/games/killchess/reset`. That page
stays on the website (`public/games/killchess/reset.html`).

## Build a new APK

You need JDK 21 (`brew install openjdk@21`) and the Android SDK (platform 36, build-tools 36).
`android/local.properties` should contain `sdk.dir=/Users/<you>/Library/Android/sdk`.

```bash
cd mobile/killchess
npm install
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
npm run build:apk   # copies www/ into the app, builds, writes public/downloads/killchess.apk
```

Before each release:

1. Bump `versionCode` (+1) and `versionName` in `android/app/build.gradle`.
2. Update `APK_VERSION` and `APK_SIZE` in `app/games/killchess/page.tsx`.

## Signing key (important)

Release builds are signed with `~/.killchess/killchess-release.jks`. Its passwords are in
`~/.killchess/keystore.properties`; set `KILLCHESS_KEYSTORE` to use a different file. The key
is not in git. **Back up both files somewhere safe.** Android only installs an update over an
existing install when it is signed with the same key. If the key is lost, players have to
uninstall the app and reinstall it, and they lose their local data.
